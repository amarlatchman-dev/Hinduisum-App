# Dharma Path

A free, open guide to Hinduism for modern life. It offers daily wisdom, structured courses, festivals, life rituals and prayers, and it works offline on any phone or computer.

## Features

| Tab | What it offers |
| --- | --- |
| **Today** | A Bhagavad Gita verse of the day, your books in progress, a daily reflection, the prayer of the day, upcoming festivals and courses in progress |
| **Academy** | Short courses on philosophy, deities, scripture, practice and temples, with progress tracking |
| **Read** | The Bhagavad Gita, Ramayana and Mahabharata in full, with Sanskrit and English. Your place in each book is saved automatically |
| **Festivals** | Major festivals by month, with their meaning, traditions and how to celebrate at home |
| **Life Events** | The samskaras (birth, naming, wedding, housewarming, last rites and more) with step-by-step guidance |
| **Puja** | Prayers and mantras in Devanagari with transliteration and meaning, favourites, read-aloud and a 108-bead japa counter |

It also has dark mode and works offline as an installable PWA. It needs no account, sends no tracking, and saves progress only on the user's own device.

## Run it

It is plain HTML, CSS and JavaScript with no build step.

```sh
python3 -m http.server 8000
# open http://localhost:8000
```

Opening `index.html` directly also works, but offline caching needs a server.

## Deploy for free

The app is fully static, so you can host it on GitHub Pages (Settings → Pages → deploy from branch), Netlify or Cloudflare Pages. On a phone, open the site and choose **Add to Home Screen** to install it like an app.

## Adding content

All content is in [`js/content.js`](js/content.js). To add more, append an object to the relevant array:

- `wisdom`: daily verses (one is chosen per day of the year)
- `courses`: Academy courses, each with `lessons` (lesson bodies may contain simple HTML)
- `festivals`: `month` is the typical Gregorian month, used for sorting
- `lifeEvents`: rites with `steps`
- `prayers`: Sanskrit, transliteration and meaning

When you change files, increase `CACHE` in `sw.js` (for example `dharma-path-v2`) so installed apps pick up the update.

## Scriptures

The texts in `texts/` are generated by `scripts/build_texts.py` from public-domain sources:

| Book | English translation | Sanskrit |
| --- | --- | --- |
| Bhagavad Gita | Annie Besant, 4th ed. (1922), all 701 verses | gita/gita open dataset |
| Ramayana | Manmatha Nath Dutt (1891–94), about 15,000 verses across all 7 kandas | Critical edition e-text |
| Mahabharata | Kisari Mohan Ganguli (1883–96), complete, all 18 parvas | — |

The Gita and Ramayana verse pairings come from the open-source [Katha](https://github.com/radhepa/Katha) project. Ganguli's text comes from [sacred-texts.com](https://sacred-texts.com/hin/maha/) via [rahulnyk/mahabharata](https://github.com/rahulnyk/mahabharata). Ramayana verses that could not be matched reliably to the Sanskrit are left out, so its verse numbers sometimes skip.

To rebuild:

```sh
git clone --depth 1 https://github.com/radhepa/Katha /tmp/katha
git clone --depth 1 https://github.com/rahulnyk/mahabharata /tmp/mbh
python3 scripts/build_texts.py /tmp/katha/assets/data /tmp/mbh/text/KMGanguli
```

## Content notes

All explanations, and the translations of the prayers and daily wisdom, are original writing for this project. The scripture translations are the public-domain editions listed above. Festival dates follow the lunar calendar and vary by year and region, so the app shows the traditional timing rather than fixed dates.
